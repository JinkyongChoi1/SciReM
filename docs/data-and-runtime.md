# Data and runtime requirements

The real Runner is currently tied to the processed category-classification pilot. It is not a general CSV-analysis product. No original research data are redistributed.

The shipped dictionary/action schema uses outcome `tagged`, grouping fields `choice_set` and `user_label`, and candidate fields `typicality`, `selfclaim_osa`, `expertise_style`, `expertise_genre`, `informative`, `distinctive`, `previous_tags`, `exemplarity`, `selfclaim_lv`, `selfclaim_cos`, `selfclaim_jw`. Optional precomputed sample flags include `subsample_6m`, `subsample_1m`, `subsample_1w`, `subsample_q75`, `subsample_q50`, `subsample_q25`, `subsample_top`. Variable names do not establish measurement validity, filter meanings or identification. The current dictionary describes preprocessed standardized variables; do not apply it to unrelated data or standardize twice.

The empirical dataset's definitive citation, version, access terms and preparation recipe must be supplied before the empirical experiments are advertised as externally reproducible. This release's scripted smoke provides no replacement for those scientific inputs. To adapt a new dataset, revise the question/dictionary and allowed action schema in `discovery_pilot.py`, permitted terms/generated R in `discovery_analysis.py`, relevant profile in `model_catalog.py`, and corresponding fixtures; then independently validate the sample/estimator/uncertainty outputs. Merely renaming columns is not enough.

Runtime: Linux/SGE allocation, Python3.10+, jsonschema; R with survival/sandwich/lmtest/fixest for real statistics; bubblewrap with available namespace support for isolation. Hosted backend needs Codex CLI and accessible model/account. Optional local backend needs compatible llama runtime/weights; optional semantic indexing needs FastEmbed. No new paid framework or hosted tracing service is required. Inference itself can consume account allowance or local compute resources.

The artifact does not contain secrets, data, weights, historical private profiles, raw transcripts or hidden evaluator reference results. Keep each run's writable context and graph separate. A directory is not an access boundary against agents running as the same OS user; actual isolation depends on the retained sandbox and runtime configuration. The live viewer implementation is included, but this release QA does not certify networking, tunnels or browser behavior on another institution's cluster.
