# Prospective evaluation

This is a proposed protocol, not a completed preregistered study or a report of new experiments.

**Primary question:** does linked scientific-judgment memory improve justified research decisions and human supervision beyond retrieving the same records as flat text?

Hold model, tools, data, role layout, review policy, context allowance and review opportunities fixed. Compare SciReM against general-purpose/flat retrieval of the same evidence records. A no-shared-memory condition is informative but cannot alone isolate judgment links. Similarity-only versus PPR and lexical versus semantic matching are mechanism ablations, not assumed improvements. Existing A/B/C development cohorts have different history policies and engineering versions; do not pool or relabel them as this comparison.

| Outcome | Operational measure | Invalid substitute |
|---|---|---|
| Evidence uptake | Prior result/limitation or researcher instruction correctly identified and applied in actual next code/design | Mentioning or citing a result |
| Justified adaptation | Blinded raters assess maintain/revise/abandon/additional-test against available evidence | Number of hypothesis changes |
| Execution alignment | Proposed test, executed code, estimator/sample/SE and output agree | A successful process exit or result file |
| Research outcome | Original-target rediscovery and independently defensible findings scored separately | Significant p-value alone |
| Human oversight | Factual reconstruction, detection of unsupported claims, appropriate redirection, later execution uptake | User satisfaction alone |
| Efficiency | Cumulative tokens, cached-token subset, time and human effort to valid outcome; include retrieval/index/repair costs | Comparing only successful calls or early cheap attempts |

Use fixed finite resource windows with no favorable-outcome stopping. Preserve errors, unsuccessful trajectories and censoring. Preregister task selection, replicate allocation, rubric, exclusions, analysis and precision/power planning before confirmatory runs. Attempts are nested within trajectories, not independent replications. Blinded independent domain evaluators should record agreement and adjudicate disagreements. Human studies need counterbalanced checkpoint tasks and appropriate institutional review where applicable.

Milestones: (1) executable source-linked prototype and explicit limits; (2) integrated human judgment revision and uptake receipts; (3) matched memory baseline and task-level repetitions; (4) human checkpoint study; (5) accessible, rights-cleared benchmark and deployment documentation. The current release addresses milestone1; it does not imply the others are complete.
